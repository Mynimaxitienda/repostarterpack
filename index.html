🚀 GITHUB Deploy Automático (.github/workflows)

Deploy automático configurado con GitHub Actions. Cada push a main despliega a Firebase Hosting.

Archivo:.github/workflows/deploy.yml

on: push branches: [main] jobs: deploy: runs-on: ubuntu-latest steps: - uses: actions/checkout@v4 - uses: FirebaseExtended/action-hosting-deploy@v0 with: repoToken: '${{ secrets.GITHUB_TOKEN }}' firebaseServiceAccount: '${{ secrets.FIREBASE_SERVICE_ACCOUNT }}' channelId: live

🔑 Google Cloud.json - Clave Secreta

Archivo clave de servicio para autenticar GitHub con Firebase. NO subir al repo, va como Secret en GitHub.

Pasos:

1. Google Cloud Console > IAM > Service Accounts > Keys > Create JSON
2. GitHub > Settings > Secrets > Actions > New Secret
3. Nombre: FIREBASE_SERVICE_ACCOUNT
4. Pegar contenido del.json

Settings > Secrets and variables > Actions Secret: FIREBASE_SERVICE_ACCOUNT_TU_PROYECTO Valor: { "type": "service_account", "project_id": "..." }

🧪 Testing Emuladores Firebase desde GITHUB/workflows

Tests automáticos con emuladores antes del deploy.

- name: Testing Emuladores Firebase run: | npm install -g firebase-tools firebase emulators:exec --only hosting "npm test" # o firebase emulators:exec --only firestore,hosting "echo OK"

Esto garantiza que el hosting y las rules funcionan antes de subir a producción.
